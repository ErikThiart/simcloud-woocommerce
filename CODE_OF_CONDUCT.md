# Code of conduct

This project welcomes people who want to improve SIMcloud for WooCommerce. This code applies to repository issues, pull requests and other project-managed discussions.

## Expected conduct

Be respectful, clear and specific. Discuss the code or proposed behaviour rather than attacking the person. Welcome questions, explain disagreements with evidence and accept constructive correction. Respect contributors' time, experience, identity and privacy.

Harassment, discrimination, threats, personal attacks, repeated disruption and publishing another person's private information are not acceptable. Do not post customer records, credentials, payment receipts or redeemable prepaid codes.

## Reporting and enforcement

Report a conduct concern to the repository maintainer through an available private GitHub contact route. If none is available, use [GitHub's abuse reporting process](https://docs.github.com/en/site-policy/acceptable-use-policies/github-community-guidelines#reporting-an-issue). Do not publish private evidence to make a report. Security vulnerabilities use the separate [private security process](SECURITY.md).

Maintainers may edit or remove inappropriate content, close or lock discussions and limit participation using GitHub moderation tools. They will consider context, severity and repeated behaviour and apply proportionate action. A participant may request review through the same private route. No response time is guaranteed.

Participation in the project means following these expectations. Contributions remain subject to the [project license](LICENSE) and [contribution guide](CONTRIBUTING.md).
