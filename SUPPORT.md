# Support

## Current project status

The project is in planning. There is no installable plugin, stable release, or compatibility guarantee. See the [roadmap](docs/roadmap.md) for planned work.

## Plugin questions and contributions

Use [GitHub Issues](https://github.com/ErikThiart/simcloud-woocommerce/issues) for documentation corrections, reproducible plugin bugs once code exists, and feature proposals. Provide a clear description, expected/actual behaviour, relevant versions, and synthetic reproduction steps. Redact all customer data and secrets.

## Account, payment, and delivery support

Customer purchases and refunds are handled by the store that accepted the payment. Merchant account access, wallet funding, provider billing, and SIMcloud transaction investigation belong in the private SIMcloud account/support channel available from [SIMcloud](https://simcloud.co.za/).

Public GitHub issues cannot safely carry account credentials, customer phone numbers, payment receipts, or private order details. A plugin issue is not a request to repeat a recharge or refund a payment. Preserve the provider request ID and use the [recovery guidance](docs/order-lifecycle.md).

## Vulnerabilities

Use the private reporting process in [SECURITY.md](SECURITY.md). Open-source availability does not include a commercial support contract or guaranteed response time.
